# Flask-News-Blog
Небольшое веб-приложение на Flask с регистрацией, авторизацией и базой данных, реализованной через ORM (SQLAlchemy). Пользователи могут публиковать, просматривать и удалять новости. Каждая новость привязана к автору.
📌 Основной функционал:
Регистрация и вход пользователей;

Добавление, отображение и удаление новостей;

Хранение данных в SQLite с использованием SQLAlchemy;

Структурированная архитектура проекта (модели, сессии, роуты);

Защита паролей (хеширование);

Статус "приватной" новости (отображается только автору).

🛠️ Используемые технологии:
Python

Flask

SQLAlchemy

WTForms

SQLite
